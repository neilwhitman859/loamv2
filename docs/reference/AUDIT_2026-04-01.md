## Duplicate Wine Names (LWIN inherited)

**1,012 groups** where same producer has multiple wines with the same name:

| Type | Groups | Explanation |
|------|-------:|-------------|
| Different colors | 136 | Legitimate — red/white/rosé of same name |
| Same color, 2 copies | 707 | LWIN format-specific codes (750ml vs magnum, etc.) |
| Same color, 3+ copies | 154 | Multi-format entries (standard + magnum + jeroboam + half) |

These are NOT data quality bugs — LWIN-7 codes are format-specific. Each has a unique LWIN identifier. Under our wine definition ("different liquid to the winemaker"), same-color duplicates should eventually be merged (the 750ml and magnum are the same liquid). The 136 different-color groups are correct as separate wines.

**Total affected:** 2,460 wines (~1.3% of 189K). Not urgent.

### Naming Mismatch Patterns (why exact match misses ~50%)

Sampled Skurnik unmatched producers:
- **Suffix:** "Anthill Farms Winery" → LWIN has "Anthill Farms"
- **Prefix:** "Antoniolo" → LWIN has "Azienda Agricola Antoniolo"
- **Punctuation:** "Bieler Pere et Fils" → LWIN has "Bieler Pere & Fils"
- **Short vs full:** "Alzinger" → LWIN has "Leo Alzinger"
- **Not in LWIN:** "Ad Ripa", "Æris [by Rhys]", "Ah-so", "Batiso" — small/natural producers outside LWIN's fine wine scope

Berliner data is extremely dirty: full addresses baked into producer names, escaped quotes, numeric codes. Only 7.2% exact match.

## Key Findings

1. **Data integrity is perfect** — zero orphans, zero bad FKs. LWIN promotion was clean.

2. **Data is extremely thin** — 189K wine identities but almost no enrichment. Zero vintages from importer data, zero scores, zero grapes, zero prices. The COLA Pass 1d added 2,917 vintages and 688 ABV values, which is the only non-identity data in canonical.

3. **All 25 non-regulatory staging sources are unlinked** — zero canonical_producer_id across all importer, retailer, and competition sources. The pre-LWIN promotion that linked these was cleared.

4. **LWIN's fine wine bias** — 42% of producers are French, sparkling wines nearly absent (4 of 189K), all producers typed as "estate", no contact info. Mass-market and natural wine producers underrepresented.

5. **COLA→wine creation blocked by normalization** — 175K candidates exist but raw fanciful names have typos, truncation, and punctuation variants that would create thousands of duplicates. UPC data will help.

6. **1,012 duplicate wine name groups** inherited from LWIN's format-specific coding. Not a data quality emergency but will need attention when LWIN-7 entries are consolidated to wine-level identity.

7. **Producer name matching needs a normalization layer** — exact matching gets 30-60% against importers, ~7% against competitions. A simple suffix/prefix stripping + punctuation normalization layer would likely push importer matching to 70-80%.

---

## Recommended Next Steps

1. **Re-link importer staging sources** — run producer matching (exact + alias + normalized) against canonical, then wine matching. This gives us vintages, grapes, farming certs, descriptions.
2. **Wait for UPC data** before COLA→wine creation (user decision).
3. **Backfill 31 wines missing country** from their producer's country.
4. **Build producer name normalization** for staging source matching (strip Winery/Vineyards/Estate suffixes, Domaine/Chateau/Azienda prefixes, normalize punctuation).
