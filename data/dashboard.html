Method stack
Sprint 7 is not another pairwise judge bakeoff. Each layer has a narrow job, and the hard requirement is that the expensive path stays small.
Layer Cheap path Heavy path Guardrail
Dossier small structured producer packet richer escalation dossier only if needed do not turn it into a prose essay
Shortlist cheap blocking / retrieval extra retrieval on frontier only candidate sets must stay small
Selector best match or none re-score only UNSURE cases explicit RELATED_BUT_DISTINCT output
Edges store positive / negative / related edges cluster only after accepted positives no hopeful transitivity
Merge application accepted SAME_AS edges only none during launch phase abstain if still unsure
Terminology (Sprint 7)
Identity dossier: a reusable structured producer packet that collects the signals the model should reason over.  ·  Shortlist select: choose the best candidate or none, rather than judging one pair in isolation.  ·  RELATED_BUT_DISTINCT: adjacent entities that share ownership, importer, family, or history without being the same producer.  ·  Accepted-edge graph: positive, negative, and related-but-distinct edges stored explicitly before any clustering.  ·  Abstention: leaving a case unresolved is success when the alternative is a false merge.
